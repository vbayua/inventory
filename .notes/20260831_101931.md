2. Procedures

1. Purchase Order

Ordering materials from supplier:
-> Create Purchase Order
-> Fill Purchase Order Form Details
-> Select Supplier to Order from
-> Add material order items

2. Receive Order

Receiving materials from PO: 
-> Create receive order from a list of PO
-> Set the quantity of received items
-> Set receive location
-> Create Receive Order

3. QC Inspection

Quality Control Process before Stock Creation by Warehouse Loading Operator Admin:
-> Receive Order with Pending Quality Control Status
-> Start inspection with predefined check list or free form check list
-> Add inspection items and decide the result (Pass/Fail/NA)
-> Set Quantity Distribution (Passed Qty, Reject Qty)
-> Approval Pending

4. Qc Inspection Approval

Processed QC Receive Order is Approved by QC Admin:
-> QC Admin reviews QC Inspection
-> Fill QC Approval Form and assign batch 
-> Set minimum quantity for this batch for low stock notification
-> Set Stock Inbound Operation to Create Initial Stock

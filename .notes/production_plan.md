Production Plan is like a Project that will result in a Product or Material after the Production process.

1. Bill of Materials
    1. Create a project (Finished Good Product Plan)
    2. Create bill of materials by adding BoM item.
    3. Set quantities needed for each BoM item for 1 Finished Good product.
    4. Project page calculated how much materials from BoM are needed to make 1 batch of product.

    Features: 
    1. Batch Calculator
    2. Bill of Material Item Picker
